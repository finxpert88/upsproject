# FSD修订9响应式验证记录

依据：PRD FR-26 / 5.6 / NFR-05 / AC-14，FSD 5.8 / SF-24 / RESP-01～06。范围是本地静态DEMO；产品及模拟数据保持英文。

## 已实现

- `responsive.css`以`.shell`内容宽度为容器断点：小于640px一列、640～980px两列、大于980px三列；宽屏沿用1288px最大外框。旧浏览器另有视口断点回退。没有禁用缩放，没有全局横向overflow隐藏。
- 窄内容区显示Menu；原有导航全部保留。设备tabs局部滚动，切换设备时当前项进入可见区域。Hero健康环、六卡顺序、风险和质量信息保留。
- 设备及告警表以完整列重排为卡片，包括发生时间、活动和确认状态；移除旧版隐藏列与中文CSS标签。其他宽表有英文滚动提示、可键盘聚焦的局部滚动区。
- 交互目标声明至少44×44 CSS px。趋势增加取样滑块、Previous Sample / Next Sample和英文数值/质量/时间读数，不依赖hover。缺失样本保持No Data。
- 表单和步骤按宽度重排。未提交的工程文本/复选框保存在当前页内存；不冒充服务端已保存。主题及尺寸变化不触发业务操作或创建新定时器。
- 弹窗保留英文标题、关闭按钮、独立滚动正文和可达操作；关闭恢复触发处或主内容焦点。窄屏全屏，使用visualViewport高度/偏移和安全区，以适配动态工具栏及软键盘。
- 报告下载弹窗提供直接Open / Save File链接，支持文件分享的浏览器提供Share File。链接访问前复核模式、代次、权限、有效期；取消分享不报告“已保存”。下载链接保留两分钟，避免过早释放Blob URL。
